# coding-practice

Beginner coding projects and practice programs while learning programming.

## PIN strength checker

Open `index.html` in a browser to use the local PIN strength checker. It evaluates the PIN in the page using simple length and pattern checks; the value is not sent to a server or saved by the site. The score is only a rough estimate, so follow the security requirements of the device or service where you use a PIN.

The checker is a standalone static page and does not require a build step or package installation.
